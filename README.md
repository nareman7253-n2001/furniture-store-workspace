# Workspace Premier

Create a premium, modern e-commerce MVP for an office furniture and workspace solutions company.

BUSINESS:
The company sells office furniture and provides complete office furnishing and workspace solutions.

The website is intended to showcase the company to a potential client, so the MVP must look like a polished real-world commercial website, not a generic AI-generated template.

CORE BUSINESS MODEL:

Sell office furniture online.

Showcase completed office furnishing projects.

Promote office furnishing and related services.

Generate customer inquiries through WhatsApp and contact forms.

DESIGN DIRECTION:

Premium

Modern

Minimal

Professional

Architectural

Clean

High-end office furniture aesthetic

Strong visual hierarchy

Large high-quality product photography

Generous whitespace

Editorial-style layouts

DO NOT:

Copy any competitor website.

Use neon colors.

Use excessive gradients.

Use futuristic/sci-fi effects.

Use excessive glassmorphism.

Use excessive animations.

Make it look like a generic SaaS dashboard.

Use cartoon illustrations.

RESPONSIVE DESIGN:
The entire website must work perfectly on:

Desktop

Tablet

Mobile

Prepare the architecture for future multilingual support including:

English

Hebrew

Arabic

The interface must be designed so RTL support can be added without restructuring the entire application.

MAIN NAVIGATION:

Home
Shop
Services
Projects
About
Contact

Include:

Shopping cart

WhatsApp CTA

Search

Mobile navigation

SHOP CATEGORIES:

Office Desks

Office Chairs

Executive Furniture

Reception Furniture

Storage & Cabinets

Meeting Room Furniture

Workstations

Accessories

SERVICES:

Office Furnishing

Workspace Planning

Delivery & Installation

Office Clearance

PROJECT TYPES:

Corporate Offices

Executive Offices

Reception Areas

Meeting Rooms

Complete Workspace Projects

BUILD A REUSABLE DESIGN SYSTEM:

Create reusable components for:

Header

Footer

Buttons

Product cards

Category cards

Project cards

Service cards

Badges

Forms

Inputs

Product gallery

CTA sections

Breadcrumbs

Filters

Modals

Toast notifications

Use realistic placeholder content and high-quality office furniture imagery.

Do not implement real payment processing yet.

Do not build a complex admin dashboard yet.

The current goal is a polished, interactive MVP that can be presented to a potential client and later extended into a production e-commerce platform.

Start by establishing the global design system, layout structure, navigation, typography, spacing, buttons, cards, and reusable components.
Do not focus on individual pages yet.
